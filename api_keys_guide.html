Stage 1+2 — News Discovery
NewsAPI
Required Free tier
Fetches top headlines from thousands of news sources. The pipeline uses the /v2/top-headlines endpoint filtered by your country (GEO_FOCUS=IN for India). Free tier gives 100 requests per day — enough for running every 30 minutes.
Free tier100 requests / day
Used inStage 1 — Discovery
.env variableNEWSAPI_KEY
NEWSAPI_KEY=your_key_here Get free key → newsapi.org
Reddit API
Recommended Free
Pulls trending stories from subreddits like r/technology, r/india, r/investing. Without this, discovery relies only on RSS feeds and NewsAPI. Create a "script" type app — takes 2 minutes.
Free tier60 requests / minute
Used inStage 1 — Discovery
.env variablesREDDIT_CLIENT_ID, REDDIT_CLIENT_SECRET
REDDIT_CLIENT_ID=your_id REDDIT_CLIENT_SECRET=your_secret REDDIT_USER_AGENT=NewsPipeline/1.0 Get credentials → reddit.com/prefs/apps
Stage 3 — Fact Verification
Bing Search API (Azure)
Recommended Free tier
Used to find corroborating sources for each story — the 3-source verification rule. Without this key, the pipeline falls back to credibility score alone (weaker fact-checking). Create a "Bing Search v7" resource on Azure — free tier is enough.
Free tier1,000 searches / month
Used inStage 3 — Verification
.env variableBING_SEARCH_API_KEY
BING_SEARCH_API_KEY=your_key_here Get key → portal.azure.com (Bing Search v7)
Stage 4 — AI Article Writing
Google Gemini API
Required (if using Gemini) Free tier
The default AI model is gemini-2.5-flash. Gemini has a generous free tier and is currently set as the article writing model in your .env. You can switch to Claude or GPT-4 by changing ARTICLE_MODEL.
Free tier15 requests / minute (flash model)
Used inStage 4 — AI Writing
.env variableGEMINI_API_KEY
GEMINI_API_KEY=your_key_here ARTICLE_MODEL=gemini-2.5-flash Get free key → aistudio.google.com
Anthropic API (Claude)
Optional Paid
Alternative AI writer. Switch by setting ARTICLE_MODEL=claude-sonnet-4-6. Claude produces higher quality articles with better reasoning. Only needed if you want to use Claude instead of Gemini.
Cost~$3 per 1M input tokens
Used inStage 4 — AI Writing
.env variableANTHROPIC_API_KEY
ANTHROPIC_API_KEY=your_key_here ARTICLE_MODEL=claude-sonnet-4-6 Get key → console.anthropic.com
OpenAI API (GPT-4 / DALL-E)
Optional Paid
Alternative AI writer using GPT-4o. Also required if you enable DALL-E image generation (IMAGE_GENERATION_ENABLED=true) — DALL-E generates a cover image for each article.
Cost~$5 per 1M input tokens (GPT-4o)
Used inStage 4 — Writing + Images
.env variableOPENAI_API_KEY
OPENAI_API_KEY=your_key_here # ARTICLE_MODEL=gpt-4o # IMAGE_GENERATION_ENABLED=true Get key → platform.openai.com
Stage 5 — Editor Dashboard
Dashboard Secret Key + API Key
Required Self-generated — no account needed
These are not from any external service — you generate them yourself using Python. DASHBOARD_API_KEY protects your approve/reject endpoints. DASHBOARD_SECRET_KEY is used internally by the app for cryptographic operations.
Run these commands once and paste the output into your .env: python -c "import secrets; print('DASHBOARD_SECRET_KEY=' + secrets.token_hex(32))" python -c "import secrets; print('DASHBOARD_API_KEY=' + secrets.token_hex(32))"
DASHBOARD_SECRET_KEY=your_generated_key DASHBOARD_API_KEY=your_generated_key

Tips to Keep Costs at $0

💡
Use Gemini Flash — it's free up to 1,500 req/day and fast enough for news articles. Only switch to Claude if quality matters more than cost.
💡
Skip NewsAPI paid tier — RSS feeds (NDTV, TOI, The Hindu, TechCrunch) are completely free and give fresh news every few minutes.
💡
Bing free tier is enough — 1,000 searches/month covers ~33 articles/day with fact-checking. Reduce MAX_STORIES_PER_RUN to stay within limit.
💡
Hetzner over DigitalOcean — same Docker setup, €3.29/month instead of $6. Saves ~$33/year for identical performance.

Stage 7 — Analytics Feedback Loop
Google Analytics 4 + Service Account
Optional Free
Pulls page views, sessions, bounce rate, and avg time on page for each published article. This data is scored and fed back to the discovery stage — high-performing categories get higher priority in future runs. Requires a Google Cloud service account JSON key file.
CostFree
Used inStage 7 — Analytics
.env variablesGA4_PROPERTY_ID, GOOGLE_SERVICE_ACCOUNT_JSON
GA4_PROPERTY_ID=123456789 GOOGLE_SERVICE_ACCOUNT_JSON=/path/to/service-account.json Set up → console.cloud.google.com
Google Search Console
Optional Free
Pulls impressions, clicks, and average search ranking position for each article URL. Uses the same Google service account as GA4 — no extra credentials needed once GA4 is set up. Helps the pipeline learn which topics rank well on Google.
CostFree
Used inStage 7 — Analytics
CredentialSame service account as GA4
# No extra keys needed — uses GOOGLE_SERVICE_ACCOUNT_JSON from GA4 setup Set up → search.google.com/search-console

Deployment Options

This project runs two processes simultaneously — the dashboard (web server) and the pipeline scheduler (background worker). Any deployment option must support both. Serverless platforms like Vercel or Netlify will NOT work.

DigitalOcean Droplet
Linux VPS — run Docker Compose directly
Recommended $6 / month
Advantages
  • Full control — runs exactly like your local machine
  • Docker Compose works out of the box
  • SQLite persists on disk — no database setup needed
  • Cheapest option for always-on deployment
  • Easy to upgrade to PostgreSQL later
  • No vendor lock-in
Disadvantages
  • You manage the server (updates, security)
  • No auto-scaling
  • Need to set up nginx + SSL manually for HTTPS
Deploy Steps
# 1. Create a $6/mo Ubuntu Droplet on DigitalOcean
# 2. SSH into it and install Docker
curl -fsSL https://get.docker.com | sh

# 3. Clone your repo
git clone https://github.com/dxtprashant07/news_pipeline_automation.git
cd news_pipeline_automation

# 4. Create and fill .env
cp .env.example .env && nano .env

# 5. Start everything
docker-compose up -d
digitalocean.com →
Railway
PaaS — deploy from GitHub, no server management
Easy setup ~$5–10 / month
Advantages
  • Connect GitHub repo — deploys automatically on every push
  • No SSH or server management
  • Built-in PostgreSQL plugin (one click)
  • Deploy dashboard and pipeline as separate services
  • Environment variables set via UI — no .env file on server
Disadvantages
  • Slightly more expensive than a VPS
  • Less control over the environment
  • SQLite not suitable — must use PostgreSQL
  • Free tier has usage limits
Deploy Steps
# 1. Go to railway.app → New Project → Deploy from GitHub
# 2. Select your repo
# 3. Add a PostgreSQL plugin
# 4. Set all .env variables in the Railway dashboard
# 5. Change DATABASE_URL to the PostgreSQL URL Railway gives you
# 6. Add a second service with start command:
# python manage.py run-all
railway.app →
Render
PaaS — similar to Railway, has a free tier
Free tier Free – $7 / month
Advantages
  • Free tier available for web services
  • Auto-deploy from GitHub
  • Managed PostgreSQL available
  • No server management needed
Disadvantages
  • Free tier web service sleeps after 15 min of inactivity
  • Background workers require paid plan ($7/mo)
  • SQLite not suitable — must use PostgreSQL
  • Cold start delay on free tier
render.com →
Hetzner Cloud
European VPS — cheapest option overall
Cheapest €3.29 / month
Advantages
  • Cheapest VPS available (~₹300/month)
  • Same setup as DigitalOcean — Docker Compose works
  • European data centers (GDPR compliant)
  • Excellent performance per rupee
Disadvantages
  • Servers in Europe/US — slightly higher latency from India
  • Same manual management as DigitalOcean
  • Less beginner-friendly UI than DigitalOcean
hetzner.com/cloud →
AWS / GCP / Azure
Enterprise cloud — overkill for this project
Enterprise $20+ / month
Advantages
  • Unlimited scalability
  • Managed databases, load balancers, CDN
  • 99.99% uptime SLA
  • Global regions including India (Mumbai)
Disadvantages
  • Complex setup — IAM, VPCs, security groups
  • Much more expensive for a single-project pipeline
  • Easy to accidentally run up a large bill
  • Overkill unless you're scaling to thousands of articles/day
